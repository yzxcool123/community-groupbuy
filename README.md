# 邻里团购（社区团购）

微信小程序全栈演示项目：用户端逛买下单、自提/送货履约与核销，配套 Express API 与 PC 管理后台。

## 目录结构

| 目录 | 说明 |
| --- | --- |
| `miniprogram/` | 微信原生小程序。Tab：首页 / 分类 / 购物车 / 我的；另含商品详情、结算、支付结果、订单、地址，以及团长侧工作台、商品管理、核销页。接口地址在 `miniprogram/config.js` 用 `ENV`（`local` / `lan` / `remote`）切换，详见本地配置。 |
| `server/` | 后端 API（Express + JWT，数据存 JSON）。提供登录鉴权、商品/分类/轮播/自提点、下单与订单、核销、管理统计等；启动时会托管同级 `admin/` 静态资源。 |
| `admin/` | PC 管理后台（静态页）。工作台概览、商品与分类、订单查询与核销、自提点维护、用户角色权限。访问路径一般为 `http://<host>:3000/admin/`。 |
| `deploy/` | 部署辅助脚本：打包推送到服务器、用 Caddy 为 API 配置 HTTPS 等。具体主机与目录以脚本内环境变量为准，密钥勿写入仓库。 |

## 主要能力

- 首页逛买、分类浏览、购物车与结算
- 履约：到店自提或送货上门；自提可选在线支付 / 到店付款，送货需在线支付
- 订单状态流转（待支付 → 已支付 / 待提货 → 已核销等）；支付为 mock，非真实微信支付
- 核销码到店核销（小程序团长端 + PC 后台）
- 管理端：商品上下架、自提点、角色权限与经营概览

## 本地运行（后端）

```bash
cd server
npm install
npm start          # 启动 API（默认端口见 server/src/config.js，一般为 3000）
# 或
npm run dev        # node --watch 热重载
npm run seed       # 重新写入演示种子数据（启动时也会尝试 seed）
```

健康检查：`GET /api/health`。管理后台：服务启动后打开 `/admin/`。

小程序：用微信开发者工具打开 `miniprogram/`，按需修改 `config.js` 的 `ENV` 指向本机或局域网 API。微信 AppId / AppSecret 仅放服务端配置或环境变量，不要写进小程序与 README。

## 说明

本仓库为演示 / MVP，支付与登录链路偏 mock，生产使用前请轮换密钥、改用环境变量，并完善安全与持久化方案。
